My adventure with Claude Code (2026-04-27):

manpageblog I have been used Claude Code for quite some time now. Like before openclaw? I used to have $100 plan back then. Models back then were quite 'dumb' however they tend to get harness like work done properly. Eversince Claude subscription was used with OpenClaw, Anthropic had to crack down on addtional, 'dumb' usage and charge them separately. While this move is welcomed, people should prefer using their opensource models hosted elsewhere because it obviously hurts other users relying on the platform.

So far I have done countless number of applications with Claude Code and it is not about marketablity of the product rather the joy of using it for a long term. First of all, you don't own the code so you wouldn't know what is exactly happening under the hood. Even if you have all figured out, touching one end of the product will have ripple effects across the product because of how the code is spagetti like, messy and unmaintainable.

On the part where harness was still widely available back then, I used to get a lot of things done, from launching docker containers to starting or stopping services. It helps to be a good debugging assistant if anyone decides to build a debug assistant into modern OSes.
