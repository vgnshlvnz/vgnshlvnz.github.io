Howto Setup your own blog in Github with custom domain (2026-04-27):

For this purpose I have picked Github because of several things. First of all is that it renders markdown files better than any competitor out there. Besides that, they allow seamless integration of custom domain to Github Pages. Basically there are many ways of hosting one's website. You could choose bloated WordPress or go for something easy to maintain and recyclable.

Make sure you have cloned Manpageblog from Github.

Before you set up anything else, make sure you have created a repository in Github.

Follow the instructions in the Github page, and set up the site. Make sure to edit blog.conf to make changes as you'd wish.

Now commit the code to the repository you have created earlier.

Next, make sure your custom domain is tied to cloudflare free tier platform because it allows easy DNS management like nobody else in this planet.

Once you have all that prepared, link your domain in Github. Make sure to do this via settings because you will likely to enter a TXT record with some values.

Once you are done, feel free to create a Page in Github for the content you have just synced to the remtoe repository.

This site runs like that. You can go and check the individual files from VGNSHLV.NZ's GitHub

Over the years hosting your personal site has never been this easier. All you have to do is minimal work and I hope you have learnt something from this post. Cheers!
